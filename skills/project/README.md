# 🧠 Skills Específicas de la Empresa / Proyecto (`skills/project/`)

Las skills en esta carpeta representan el conocimiento especializado que los agentes necesitan para trabajar eficazmente en los repositorios de esta empresa:

- **SDKs internos o librerías corporativas**: Cómo usar el cliente interno de autenticación, mensajería o logging de la empresa.
- **APIs y contratos internos**: Documentación de microservicios dependientes, gateways o bases de datos compartidas.
- **Pipelines y CI/CD**: Scripts de compilación, comandos de base de datos local (migraciones, seeds).

Cada skill debe contener un archivo `SKILL.md` con frontmatter (`name`, `description`) y el detalle técnico.
