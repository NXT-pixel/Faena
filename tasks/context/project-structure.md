## Directory Conventions
- `agents/`: Specialized AI agent personas for design, architecture, and coding
- `commands/`: Procedural guides and prompt templates
- `rules/`: Quality gates, TDD guidelines, and standards
- `tasks/`: Active tickets, TRDs, and implementation task breakdowns
- `tasks/context/`: Core architecture, technology, and progress context
